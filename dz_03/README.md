# Задание: локальная сеть в Cisco Packet Tracer

Соберите локальную сеть из восьми компьютеров, двух коммутаторов Switch 2950-24 и одного концентратора Hub-PT. Назначьте компьютерам адреса `192.168.0.1`–`192.168.0.8` с маской `255.255.255.0`.

Подберите прямые и перекрёстные кабели для соединений между компьютерами, коммутаторами и концентратором. После настройки проверьте связь между PC5 и PC1 командой `ping`, затем проследите прохождение ICMP-пакета в режиме симуляции.
