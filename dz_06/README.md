# Задание: транспортный уровень

Раскройте назначение транспортного уровня и объясните понятия сегментации, порта и сокета. Сравните TCP и UDP по способу установления соединения, гарантии доставки и применению.

Опишите установление TCP-соединения через `SYN`, `SYN-ACK` и `ACK`, а также механизмы, позволяющие TCP отслеживать получение и порядок данных. В качестве примеров использования UDP рассмотрите DNS, DHCP, TFTP и SNMP.

Файл [nat_Cisco.pkt](src/nat_Cisco.pkt) сохранён в папке как практический проект Packet Tracer.
