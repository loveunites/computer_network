# Задание: расчёт IPv4-подсетей

Для каждой исходной сети подберите подходящую маску и рассчитайте параметры получившихся подсетей.

1. Разделите сеть `192.168.0.0` на восемь подсетей. Укажите адреса подсетей и количество узлов, доступных в каждой.
2. Для сети `192.168.50.0` определите адреса и диапазоны подсетей, рассчитанных с маской, подходящей для размещения 30 узлов в каждой.
