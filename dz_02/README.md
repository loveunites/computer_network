# Задание: DHCP

Подготовьте описание работы DHCP и объясните, какие сетевые параметры протокол может назначать устройству. Сравните DHCP с RARP и BOOTP, перечислите варианты выдачи адресов и изложите порядок обмена DORA.

Также опишите продление аренды, возможные сложности при динамической адресации и ситуации, в которых устройствам предпочтительно задавать постоянный IP-адрес.

Отдельное выполненное задание по расчёту IPv4-подсетей приведено в документе [subnets.docx](assets/subnets.docx).
