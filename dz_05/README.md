# Задание: адресация и схемы маршрутизации

## Расчёт подсетей

1. Составьте схему адресации для пяти зданий, в каждом из которых подключено от 15 до 25 устройств. Каждому зданию назначьте отдельную подсеть.
2. Рассчитайте адресацию сети, где нужно разместить не менее 20 подсетей и по 10 узлов в каждой.

Для обоих случаев укажите выбранную маску и параметры подсетей.
